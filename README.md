# 🔐 NovaSOC

## 🚀 Overview

NovaSOC is a cloud-hosted cybersecurity platform that simulates a real-world Security Operations Center (SOC), Security Information and Event Management (SIEM), and Security Orchestration Automation and Response (SOAR) environment.

The platform generates live cyberattack telemetry, performs automated threat detection, visualizes attack activity through enterprise dashboards, and executes simulated incident response workflows.

### Key Capabilities

* Real-time threat detection
* Automated SOAR response workflows
* Global cyber threat intelligence map
* MITRE ATT&CK analytics
* Incident management dashboard
* PostgreSQL-backed telemetry pipeline
* AWS cloud deployment
* ELK Stack integration
* Automated IP blocking simulation
